# Установка актуального ПростоJPG

Всегда используй официальный магазин:
[ПростоJPG](https://chromewebstore.google.com/detail/простоjpg/djjocjgglhbkcfclclilmamlcoggoole).

Если пользователь уже сообщил об установленном расширении или доступный браузер показывает «Удалить из Chrome»/аналогичный статус, повторная установка не нужна. При неизвестном статусе проверь страницу магазина или доступный UI расширений; не читай приватные профили и cookies.

На Windows с локальным терминалом прочитай `scripts/browser-setup.ps1`, затем выполни через доступный PowerShell:

```text
powershell -NoProfile -File <абсолютный-путь-к-browser-setup.ps1> -ExtensionOnly -PlanOnly
powershell -NoProfile -File <абсолютный-путь-к-browser-setup.ps1> -ExtensionOnly
```

`-ExtensionOnly` обязателен: этот запуск нужен только для расширения, повторно устанавливать плагин не требуется. Скрипт обнаруживает Chrome и Яндекс Браузер и открывает магазин в обоих найденных браузерах; если найден один — только в нём. Не меняй ExecutionPolicy и политики установки. Если запуск PS1 запрещён окружением, открой ту же ссылку через доступный браузерный инструмент/разрешённый запуск найденного браузера.

При наличии браузерного управления проведи действия «Добавить»/«Установить» через обычный интерфейс. Если подтверждение требует участия пользователя или инструмент не имеет доступа к этому браузеру, сообщи один требуемый шаг. `awaiting-browser-confirmation` означает только открытие страницы, а не установленное расширение. Завершение подтверждай реальным статусом магазина/браузера. Не устанавливай распакованную копию, не записывай реестр расширений и не обходи подтверждения.

На других ОС открой официальный магазин во внешнем Chrome/совместимом браузере инструментами окружения. IAB не используется для установки расширения Chrome/Яндекс. Не утверждай, что браузер установлен, если обнаружить его не удалось. Установка ПростоJPG и подключение управления внешним браузером к Codex — разные действия; не заявляй, что расширение само обеспечивает это подключение. Скачивание исходников самим Codex может продолжаться, пока пользователь подтверждает добавление расширения.
