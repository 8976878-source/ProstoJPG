# Создание карточек из браузерного расширения

В расширении 1.0.21 кнопка **Дизайн карточек с ПростоJPG и GPT** расположена над **Инструменты Селлера**. Внутри:

- **Создать похожие карточки** → WB / OZON → артикул.
- **Создать карточки с моим товаром** → WB / OZON → артикул + фото товара.

Расширение открывает товар в том внешнем браузере, где оно установлено, собирает фото существующим коллектором и скачивает их в память. Оно не создаёт ZIP через Chrome Downloads: байты фото передаются порциями локальному native messaging мосту. Мост вызывает официальный Codex App Server по stdio, запрашивает встроенную генерацию для каждого фото и детерминированно собирает ZIP через `cards.py`. Все исходники и результаты сохраняются в локальной папке заданий. Фотографии передаются сервису генерации Codex; cookies и ключи не выгружаются мостом.

## Установка

Единый `install.bat` из репозитория устанавливает плагин 1.0.3 и, если Codex CLI возвращает `installedPath`, запускает `bridge/install.ps1` из установленного пакета. Мост регистрируется для текущего пользователя в Chrome и Яндекс; права администратора не нужны. Стандартный installer не изменяет политики браузера и не отключает защиту.

Ручной запуск из распакованного пакета, если CLI не вернул путь установки:

```text
powershell -NoProfile -File <путь-плагина>/bridge/install.ps1 -CodexPath <путь-к-codex.exe>
```

Нужны Python 3.10+ и Pillow; установщик обнаруживает Python Codex либо доступный Python. Pillow при необходимости устанавливается в локальную папку моста, без изменения основного Python. Для теста доступен `-PlanOnly`; `-NoRegister` создаёт файлы без регистрации браузеров. При тестировании распакованного расширения передай `-ExtensionId <фактический-id>`: доступ ограничен ровно указанным ID, wildcard отсутствует. Для магазина используется `djjocjgglhbkcfclclilmamlcoggoole`.

## Вход и ошибки

Вход в desktop-приложение и вход локального Codex CLI могут различаться. При отсутствии CLI-входа мост начинает штатный `account/login/start` с типом `chatgpt`, а расширение открывает официальный адрес входа в том же браузере. Пользователь завершает вход; после проверки аккаунта обработка продолжается. При существующем API-аккаунте мост не переключает его и не запускает платный Images API автоматически. Для входа вручную — `codex login`.

Сначала проверяются `modelProvider/capabilities/read` и `account/read`. Поддержка провайдером не доказывает доступ по конкретному аккаунту; успех каждого фото подтверждается реальным завершённым событием `imageGeneration` с файлом/данными результата. Отсутствие генерации, лимит, отказ, запрос интерактивного подтверждения или ошибка сети не подменяются исходниками. Неполный набор блокирует готовый ZIP. `Остановить создание` сохраняет исходники.

Проверка маркетплейса остаётся возможной и в обычном браузере. При CAPTCHA или входе пользователь сам завершает нужный шаг. Мост не обходит защиту WB/Ozon. Если расширение ещё не обновлено до 1.0.21 в магазине, новая кнопка там не появится: требуется публикация этой версии Chrome Web Store.
