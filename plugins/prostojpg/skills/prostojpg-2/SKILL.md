# Создать схожие карточки

Режим 2 уже выбран. Прочитай [общий сценарий ПростоJPG](../product-cards/SKILL.md) и выполни общие шаги и режим 2. Скрипты и ссылки на ресурсы общего сценария разрешай относительно каталога `product-cards`, а не этой папки.

Не показывай меню выбора режимов. Сохрани уже указанные маркетплейс и артикул, запроси только недостающие данные. Фото товара для замены здесь не требуется. Проведи установку актуального расширения по общему сценарию. Самостоятельно собери галерею карточки и скачай исходный ZIP через `product-cards/scripts/download.py`, подготовь задание с `--mode 2`. Не жди загрузки архива через расширение. Для каждого исходного фото используй точный промпт режима 2 из общего сценария и доступный генератор изображений. После всех результатов собери новый ZIP. При недоступной генерации сообщи об этом; исходники не выдавай за новые карточки.
