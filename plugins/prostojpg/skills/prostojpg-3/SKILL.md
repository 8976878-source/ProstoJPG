# Создать схожие карточки с вашим товаром

Режим 3 уже выбран. Прочитай [общий сценарий ПростоJPG](../product-cards/SKILL.md) и выполни общие шаги и режим 3. Скрипты и ссылки на ресурсы общего сценария разрешай относительно каталога `product-cards`, а не этой папки.

Не показывай меню выбора режимов. Сохрани уже указанные маркетплейс, артикул и вложенное фото товара. Запроси только недостающее; без фото нового товара генерацию не начинай. Покажи ссылку на актуальное расширение, получи исходники через него, подготовь задание с `--mode 3 --subject <путь-к-фото-товара>`. Для каждого исходника передай генератору исходную карточку и фото нового товара с точным промптом режима 3 из общего сценария. После всех результатов собери новый ZIP. При недоступной генерации сообщи об этом; не подменяй замену товара исходниками.
