# ПростоJPG — карточки WB и Ozon в Codex

Три режима: скачать фото и видео по артикулу через расширение ПростоJPG, создать похожие карточки, создать карточки с вашим товаром. Готовые фото собираются локально в новый ZIP с исходными пропорциями и минимум 1200 пикселей по короткой стороне.

## Установка

1. Установите [актуальное расширение ПростоJPG](https://chromewebstore.google.com/detail/простоjpg/djjocjgglhbkcfclclilmamlcoggoole).
2. Добавьте публичный источник плагинов и установите плагин командами ниже.
3. Начните новый чат в Codex.
5. Вызовите плагин и выберите режим; также доступен скилл `$product-cards`.

```text
codex plugin marketplace add 8976878-source/ProstoJPG
codex plugin add prostojpg@prostojpg-marketplace
```

Публичный репозиторий: [8976878-source/ProstoJPG](https://github.com/8976878-source/ProstoJPG). Для установки из ZIP распакуйте `prostojpg-marketplace` и выполните `codex plugin marketplace add ./prostojpg-marketplace` из родительской папки, затем ту же команду `codex plugin add`.

Локальный пакет версии 1.0.0 принят установщиком Codex. Создание карточек требует доступной генерации изображений. Для локальной сборки нужны Python 3.10+ и Pillow; в desktop Codex могут использоваться встроенные зависимости. Плагин не требует собственного сервера или API-ключа для встроенной генерации.

## Как работает

Скачивание выполняется установленным расширением, с участием пользователя. Версия 1.0.19 не имеет внешнего API команд для Codex. Генерация выполняется отдельно для каждого исходного фото. Для замены предмета пользователь прикрепляет фото товара. Обработчик проверяет комплектность и создаёт новый архив без перезаписи исходного. Другие пропорции результата генерации исправляются вписыванием в исходное соотношение сторон с белыми полями.

## Публикация

Этот каталог можно размещать в публичном репозитории и добавлять в Codex как marketplace. Для общего каталога OpenAI подготовлен отдельный ZIP с содержимым `plugins/prostojpg` в корне архива. Публикация в общем каталоге требует проверенного издателя и прохождения проверки; наличие ZIP не означает прохождения модерации.
