# ПростоJPG от ПростоСеллер

Создавайте карточки товаров для Wildberries и Ozon по загруженным фото. Промпты уже встроены — писать их не нужно.

## 1. Установите расширение для браузера

[![ПростоJPG для Chrome и Яндекс Браузера](plugins/prostojpg/assets/instruction-1.jpg)](https://chromewebstore.google.com/detail/простоjpg/djjocjgglhbkcfclclilmamlcoggoole)

[**Установить расширение ПростоJPG**](https://chromewebstore.google.com/detail/простоjpg/djjocjgglhbkcfclclilmamlcoggoole) в Chrome или Яндекс Браузер.

## 2. Скачайте нужные фото из карточек товара

![Скачивание фото и видео через Инструменты Селлера](plugins/prostojpg/assets/instruction-2.jpg)

Откройте ПростоJPG → **Инструменты Селлера** → **Скачать фото и видео**. Выберите WB или Ozon, введите артикулы и нажмите **Скачать архивы по списку**. Сохраните ZIP с исходными фото на компьютере.

## 3. Установите плагин для Codex

[**Скачать плагин для Codex**](downloads/prostojpg-plugin-1.1.1.zip) · [**Открыть страницу плагина**](https://github.com/8976878-source/ProstoJPG)

Чтобы локальный Codex установил плагин, напишите ему:

> Установи https://github.com/8976878-source/ProstoJPG/

Также доступен [**плагин для Claude Code**](downloads/prostojpg-claude-plugin-1.1.1.zip). Для его установки напишите:

> Установи плагин ПростоJPG для Claude Code из https://github.com/8976878-source/ProstoJPG/

Агент с доступом к вашему компьютеру выполнит установку. Расширение подтверждается в окне браузера. Веб-чат без локального доступа не может установить ПО на компьютер. Подробнее: [инструкция установки](INSTALL.md).

Для генерации в Claude Code нужен также установленный Codex с входом через аккаунт ChatGPT и доступной генерацией изображений. Дополнительный плагин генератора и API-ключ не нужны.

## 4. Выберите нужную команду

**ProstoJpg-1 — Скачивание через расширение.** Помощник предложит установить расширение и скачать ZIP самостоятельно. Пример: выберите `ProstoJpg-1`, сообщите WB/Ozon и артикул. Если предоставите управление внешним Chrome/Яндекс Браузером и инструменты поддерживают работу с расширением и скачиванием, помощник выполнит эти шаги через браузер.

**ProstoJpg-2 — Похожие карточки.** Пример: выберите `ProstoJpg-2` и приложите три исходных фото или ZIP с ними. Помощник создаст три новые карточки, сохранив ваш товар узнаваемым, и соберёт ZIP.

**ProstoJpg-3 — Замена товара.** Пример: выберите `ProstoJpg-3`, загрузите две исходные карточки, а последним отдельным файлом — фото своего товара. Помощник заменит товар на обеих карточках и соберёт ZIP. Фото товара не входит в исходные карточки.

**В Codex:** выберите навык `$prostojpg-1`, `$prostojpg-2`, `$prostojpg-3` или напишите его название обычным сообщением. Точный способ выбора через интерфейс зависит от клиента. После установки при необходимости откройте новый чат, чтобы обновился список навыков.

**В Claude Code:** используйте `/prostojpg:prostojpg-1`, `/prostojpg:prostojpg-2` или `/prostojpg:prostojpg-3` соответственно.

Для создания карточек достаточно выбрать режим и загрузить фото. Артикул и собственный промпт не нужны. Встроенный браузер Codex для WB/Ozon в сценарии скачивания не используется.

## Результат и генерация

- Соотношение сторон каждого фото сохраняется как у оригинала.
- Короткая сторона — не менее 1200 px; при необходимости изображение масштабируется.
- Если генератор вернул другую пропорцию, добавляются белые поля без обрезки товара.
- ZIP включает новые фото и отчёт `manifest.json`. Видео не генерируются.
- Исходники и готовый архив сохраняются на компьютере; для генерации изображения передаются OpenAI.

Используется встроенный инструмент изображений Codex через аккаунт ChatGPT. Название конкретной модели не закреплено в плагине; доступ и лимиты определяет Codex. Отдельная модель на тысячах карточек не обучалась: плагин использует готовые промпты. Он не выдаёт исходное фото или незавершённую обработку за результат генерации.

Python 3.11+ и Pillow нужны только при обработке и сборке ZIP. Установка плагина не настраивает браузерный мост, не устанавливает Python/Pillow и не записывает настройки расширений в реестр. Генерация может занимать несколько минут на каждое фото.

## Бесплатный тариф и Plus

Плагин бесплатный. На Free доступен Codex и ограниченная, более медленная генерация изображений; фактический доступ проверяется в вашем аккаунте. Plus за $20 в месяц даёт более высокие лимиты, но не фиксированный пакет изображений. Число генераций за месяц не гарантируется. Один исходник в плагине — один запрос генерации; повторные варианты требуют дополнительных запросов. [Актуальные условия Codex](https://chatgpt.com/codex/pricing/) · [Условия Plus](https://help.openai.com/en/articles/6950777-what-is-chatgpt-plus).
