**ПростоJPG от ПростоСеллер**

Плагин для Codex, который помогает быстро работать с карточками товаров на Wildberries и Ozon.

**Что умеет плагин:**

1. **Скачать фото и видео по артикулу**  
   Вы вводите артикул WB или Ozon — плагин скачивает все фото и видео с карточки.
2. **Создать похожую карточку**  
   Плагин берёт исходные фото и с помощью ИИ делает похожие: немного меняет ракурс и детали, улучшает качество, но товар остаётся узнаваемым.
3. **Создать похожую карточку с вашим товаром**  
   Вы вводите артикул и прикрепляете фото своего товара. ИИ сохраняет стиль и композицию оригинала, но заменяет главный предмет на ваш товар.

**Как пользоваться:**

1. Установите плагин в Codex.
2. Установите браузерное расширение «ПростоJPG»:  
   [https://chromewebstore.google.com/detail/простоjpg/djjocjgglhbkcfclclilmamlcoggoole](https://chromewebstore.google.com/detail/простоjpg/djjocjgglhbkcfclclilmamlcoggoole)
3. Вызовите нужный режим плагина одной из команд:
   - `/ProstoJpg-1` — Скачать фото и видео по артикулу.
   - `/ProstoJpg-2` — Создать схожую карточку.
   - `/ProstoJpg-3` — Создать схожую карточку с вашим товаром.
4. В зависимости от выбранного режима введите артикул (и при необходимости добавьте фото товара).
5. Плагин сам скачает исходные материалы, обработает их и сохранит результат.
6. В конце вы получите ZIP-архив с готовыми изображениями.

**Что получите на выходе:**

- Фото в пропорциях оригинала.
- Разрешение — не менее 1200 px по короткой стороне.
- Все файлы сохраняются на вашем компьютере.
- Готовый архив можно сразу использовать для карточек.

**Почему это удобно:**

- Экономит время.
- Не нужно вручную искать и скачивать фото.
- Помогает быстро обновлять карточки на WB и Ozon.
- Всё работает локально.
- Подходит продавцам, дизайнерам и агентствам.

**Установка из GitHub:**

Чтобы не вводить команды вручную, отправьте Codex:

> Установи https://github.com/8976878-source/ProstoJPG/

Codex на Windows с доступом к локальному терминалу может прочитать [инструкцию установки](INSTALL.md), скачать и запустить [единый install.bat](https://github.com/8976878-source/ProstoJPG/raw/refs/heads/main/install.bat). Дополнительные файлы и распаковка не нужны. BAT сам устанавливает плагин со всеми скиллами и открывает страницу расширения в каждом найденном Chrome и Яндекс Браузере. Подтвердите «Добавить расширение» в каждом браузере.

Обычный веб-чат GPT без доступа к компьютеру не может выполнить локальную установку. Сам репозиторий не регистрирует автоматическую установку по ссылке в клиенте GPT или Codex; агент выполняет её в ответ на просьбу пользователя, если у него доступны нужные инструменты. [Архив с тем же единым BAT](downloads/prostojpg-install-windows.zip).

Для ручной установки:

```text
codex plugin marketplace add 8976878-source/ProstoJPG
codex plugin add prostojpg@prostojpg-marketplace
```

После установки начните новый чат. [Скачать пакет ZIP](downloads/prostojpg-marketplace.zip).

**Технические особенности:**

- `/ProstoJpg-1`, `/ProstoJpg-2` и `/ProstoJpg-3` распознаются как текстовые обращения к установленному плагину. Они не добавляются в системное меню slash-команд Codex. Если клиент не отправляет такое сообщение, используйте встроенный вызов скиллов `$prostojpg-1`, `$prostojpg-2`, `$prostojpg-3` или выберите скилл в `/skills`.
- Codex сам открывает карточку по артикулу **во внешнем Chrome или Яндекс Браузере**, собирает ссылки на фото и видео из её галереи и скачивает файлы локальным загрузчиком. Встроенный браузер Codex для WB/Ozon не используется из-за возможных блокировок VPN. При недоступности CDN из локального процесса скилл использует скачивание отдельных медиа доступным инструментом внешнего браузера и сам собирает ZIP из этих файлов. Нужны подключение управления внешним браузером, сеть и локальные файлы. CAPTCHA или вход могут потребовать действия пользователя. Видео поддерживается в MP4/MOV/WebM; потоковые M3U8/MPD не выдаются за скачанные файлы.
- Скилл также проводит установку актуального ПростоJPG: открывает официальный магазин в найденных Chrome и Яндекс Браузере. Подтверждение добавления расширения выполняется в браузере. Если оно уже установлено, повторная установка не требуется. Загрузка архива самим Codex работает независимо от расширения.
- Подготовка и сборка ZIP выполняются локально. ИИ-генерация выполняется доступным сервисом Codex, куда передаются исходные фото; генерация зависит от доступности инструмента и лимитов аккаунта. Для локальной обработки нужны Python 3.10+ и Pillow.
- Обрабатываются все исходные фото. Если генератор вернул другие пропорции, фото вписывается с белыми полями. Неполный набор не выдаётся за готовый архив.
