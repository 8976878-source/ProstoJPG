# Установка ПростоJPG

Сначала установите [расширение ПростоJPG](https://chromewebstore.google.com/detail/простоjpg/djjocjgglhbkcfclclilmamlcoggoole) в Chrome или Яндекс Браузере. Расширение скачивает фото и видео; создание новых карточек выполняет плагин.

## Codex

```text
codex plugin marketplace add 8976878-source/ProstoJPG
codex plugin add prostojpg@prostojpg-marketplace
```

Если пользователь явно попросил локальный Codex установить этот репозиторий на Windows, прочитайте и выполните один `install.bat`. Его PowerShell-код встроен внутрь файла: соседние скрипты не нужны. Он находит Codex, выполняет две команды выше и открывает официальный магазин в найденных Chrome и Яндекс Браузере. Пользователь подтверждает установку расширения в каждом браузере. Если браузеров нет, отчёт прямо сообщает об этом.

Если исполняется копия BAT из интернета, сначала прочитайте файл. Перед запуском чужого BAT не считайте содержимое доверенным только из-за ссылки. Здесь публикуется проверяемый исходный текст установщика.

При обновлении повторите команды установки; если клиент использует старый каталог, обновите marketplace средствами вашей версии Codex и откройте новый чат. Не удаляйте чужие навыки. Старые отдельно установленные навыки `product-cards` могут оставаться вне плагина: удаляйте только известную копию ПростоJPG по запросу пользователя.

## Claude Code

```text
claude plugin marketplace add 8976878-source/ProstoJPG
claude plugin install prostojpg@prostojpg-marketplace
```

Внутри Claude Code доступны `/prostojpg:prostojpg-1`, `/prostojpg:prostojpg-2`, `/prostojpg:prostojpg-3`. Для создания фото нужен установленный Codex и вход через ChatGPT (`codex login`). Аккаунт и версия Codex должны поддерживать генерацию изображений. BAT устанавливает плагин именно в Codex; установку Claude выполняют команды выше или агент по явному запросу пользователя.

## Что делает BAT

В версии 1.0.3 BAT после установки плагина запускал `bridge/install.ps1`: настраивал Native Messaging для Chrome/Яндекса, при необходимости устанавливал Python и Pillow, записывал подключение моста в пользовательский реестр.

В 1.1.0 обязательный мост удалён. BAT только устанавливает плагин Codex с тремя навыками и открывает магазин расширений. Python, Pillow и настройки реестра не устанавливаются. Это убирает лишние операции при установке; зависимости обработки подключаются только при первом создании карточек.

Предыдущую конфигурацию моста BAT автоматически не удаляет. Установка не требует прав администратора, не меняет ExecutionPolicy, политики браузеров и защиту системы.

Проверка плана без изменений: `install.bat --plan`. Установка без открытия браузеров: `install.bat --no-browser`. Успех установки плагина подтверждается ответом Codex. Открытие магазина не подтверждает установку расширения.

Веб-чат GPT/Codex без доступа к компьютеру не может запускать BAT и устанавливать локальное ПО. В локальном клиенте достаточно явного запроса «Установи https://github.com/8976878-source/ProstoJPG/», если он имеет необходимые инструменты и разрешения.
