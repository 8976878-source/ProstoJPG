# Установка ПростоJPG для Windows

Пользователю достаточно отправить Codex запрос:

> Установи ПростоJPG из https://github.com/8976878-source/ProstoJPG вместе со скиллами и открой установку расширения в Chrome и Яндекс Браузере, если они установлены.

Codex с локальным терминалом может прочитать этот файл и выполнить установщик. Одна ссылка без просьбы установить не является гарантированным запуском: способ обработки ссылки выбирает клиент Codex.

## BAT-файлы

Скачайте [архив установки](downloads/prostojpg-install-windows.zip), распакуйте **всю папку** и запустите:

- `install.bat` — установить плагин и все его скиллы, затем открыть официальный магазин в найденных Chrome и Яндекс Браузере.
- `install-extension.bat` — только открыть установку расширения, без команд Codex.

BAT-файлам нужен соседний каталог `setup` из архива. Они используют установленный Windows PowerShell. Установщик не устанавливает новые браузеры.

В каждом браузере подтвердите **Добавить расширение**. Пока подтверждения нет, расширение не установлено. Если расширение уже есть, магазин покажет это. Если браузеры не найдены, откройте [официальную страницу](https://chromewebstore.google.com/detail/простоjpg/djjocjgglhbkcfclclilmamlcoggoole) в совместимом браузере.

## Выполнение агентом

1. Получите исходники этого публичного репозитория обычным разрешённым способом. Прочитайте `setup/install.ps1` перед запуском; не исполняйте скачанный текст через `Invoke-Expression`.
2. Для проверки без изменений выполните `powershell.exe -NoProfile -File .\setup\install.ps1 -PlanOnly`.
3. По запросу пользователя на установку выполните `powershell.exe -NoProfile -File .\setup\install.ps1`. Он сам вызывает `codex plugin marketplace add 8976878-source/ProstoJPG`, затем `codex plugin add prostojpg@prostojpg-marketplace`. Скиллы включены в плагин и не требуют отдельного копирования в глобальные папки.
4. Если агент должен открывать браузеры через собственный инструмент управления, выполните установщик с `-NoBrowserLaunch`, затем откройте официальный магазин в каждом найденном браузере этим инструментом. Для браузерной части отдельно доступен `-ExtensionOnly`.
5. Проверьте результат JSON: `plugin.status` должен быть `installed` с версией; `browsers[].extensionStatus=awaiting-browser-confirmation` означает только открытие страницы, а не завершение установки. При ошибке первой команды вторая не запускается. `open-failed` требует вручную открыть ссылку в этом браузере. Не объявляйте расширение установленным до проверки через браузер.
6. После установки начните новый чат и вызовите `$prostojpg-1`, `$prostojpg-2` или `$prostojpg-3`.

Если отсутствует CLI Codex, локальный терминал или доступ к сети, автоматическая установка плагина не выполняется. При ограничениях компьютера используйте разрешённый способ установки; скрипт не меняет ExecutionPolicy, политики браузеров, разрешения и настройки защиты.
