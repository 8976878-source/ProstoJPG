# Установка ПростоJPG одним сообщением

Отправьте Codex:

> Установи https://github.com/8976878-source/ProstoJPG/

На Windows Codex с локальным терминалом может скачать, прочитать и запустить единый `install.bat`. Он установит плагин со всеми скиллами, настроит локальное подключение расширения к Codex и откроет официальный магазин в каждом найденном Chrome и Яндекс Браузере. Дополнительные файлы рядом с BAT и ручной ввод команд плагина не нужны.

[Скачать единый install.bat](https://github.com/8976878-source/ProstoJPG/raw/refs/heads/main/install.bat) · [ZIP с этим файлом](downloads/prostojpg-install-windows.zip)

В каждом браузере подтвердите **Добавить расширение**. Отчёт об открытии страницы не означает, что расширение установлено. Если расширение уже установлено, магазин покажет это. Если браузеры не найдены, откройте [официальную страницу](https://chromewebstore.google.com/detail/простоjpg/djjocjgglhbkcfclclilmamlcoggoole) в совместимом браузере. Установщик не устанавливает новые браузеры.

## Инструкция для Codex

1. По явной просьбе пользователя установить репозиторий получите `INSTALL.md` и `install.bat` из https://github.com/8976878-source/ProstoJPG. Прочитайте BAT целиком: PowerShell-код находится в самом файле после строки `# PROSTOJPG_POWERSHELL`. Не запускайте непроверенные внешние команды.
2. Сохраните BAT как новый локальный файл без перезаписи пользовательских файлов. Используйте разрешённые загрузку и локальное выполнение; не обходите обязательные подтверждения и ограничения среды.
3. Выполните `install.bat --plan` из его папки. Проверка ничего не устанавливает и не открывает браузеры. JSON показывает найденный Codex, Chrome и Яндекс.
4. Выполните `install.bat` для полной установки. BAT сам вызывает `codex plugin marketplace add 8976878-source/ProstoJPG`, затем `codex plugin add prostojpg@prostojpg-marketplace`. Все скиллы входят в плагин, отдельно их копировать не требуется. BAT не ждёт нажатия клавиши и пригоден для запуска агентом.
5. Если браузеры нужно открывать собственным инструментом управления агента, используйте `install.bat --no-browser`, затем откройте официальный магазин в каждом найденном браузере этим инструментом. Этот флаг устанавливает плагин и скиллы, но не открывает окна.
6. Подтвердите `plugin.status=installed`, версию и `bridge.status=installed` в JSON. Мост устанавливается из `installedPath/bridge/install.ps1`, возвращённого Codex CLI. Статус `bridge.status=unavailable` требует [ручной настройки моста](plugins/prostojpg/skills/product-cards/references/extension-design.md) и не означает готовность кнопок дизайна. `browsers[].extensionStatus=awaiting-browser-confirmation` означает открытие страницы; `not-opened` — страницы не открывались; `open-failed` — ошибка запуска браузера. Не объявляйте расширение установленным без проверки в браузере. При ошибке команды Codex или настройки моста установщик останавливается с ненулевым кодом.
7. Предложите начать новый чат и вызвать `$prostojpg-1`, `$prostojpg-2` или `$prostojpg-3`.

Скачать BAT и выполнить его самостоятельно тоже можно. Для плагина используются Windows PowerShell и установленный Codex CLI. Для кнопок дизайна нужен Python 3.10+ (обнаруживается встроенный Python Codex или Python из PATH); Pillow при необходимости устанавливается только в папку моста. Мост сохраняется в `%LOCALAPPDATA%/ProstoJPG/codex-bridge/1.0.3`, а задания — в соседней папке `jobs`. Он регистрирует Native Messaging host для текущего пользователя, без прав администратора и без изменения политик расширений.

В расширении версии 1.0.21 откройте **Дизайн карточек с ПростоJPG и GPT** над **Инструменты Селлера**, выберите похожие карточки либо карточки с вашим товаром, укажите WB / OZON и артикул. Во втором варианте приложите фото товара. При первом запуске расширение предложит штатный вход в Codex CLI через ChatGPT. Вход в приложение Codex и вход CLI могут различаться. Нужна доступная встроенная генерация; оплачиваемый Images API и API-ключи автоматически не подключаются. Фото собираются во внешнем браузере и передаются сервису генерации Codex; готовый ZIP сохраняется локально. Публикация нового расширения в Chrome Web Store выполняется отдельно от публикации плагина на GitHub.

## Доступность

- Локальный Codex на Windows с терминалом и интернетом: поддерживается этот установщик.
- GPT с разрешённым доступом к локальному компьютеру: зависит от доступных инструментов и разрешений среды.
- Обычный веб-чат GPT без локального доступа: не может установить ПО на компьютер пользователя.

Запрос «Установи …» выражает намерение пользователя; одна ссылка без такого намерения не гарантирует запуск установки. Репозиторий не может принудительно зарегистрировать обработчик ссылок в GPT или Codex. При отсутствии терминала, Codex CLI, доступа к сети или требуемого разрешения сообщите конкретное ограничение. BAT не меняет ExecutionPolicy, реестр расширений, политики браузера или защиту компьютера.

Разработчику: `install.bat` собирается из поддерживаемого `setup/install.ps1` скриптом `tools/build_installer.py` в исходном рабочем проекте. Для нестандартных путей предусмотрены переменные `PROSTOJPG_CODEX_PATH`, `PROSTOJPG_CHROME_PATH`, `PROSTOJPG_YANDEX_PATH`; их значения передаются как пути, а не как код. `PROSTOJPG_SKIP_DISCOVERY=1` отключает поиск стандартных путей и используется для диагностики и тестов.
