# ПростоJPG: установка по просьбе пользователя

Если пользователь явно пишет «Установи https://github.com/8976878-source/ProstoJPG/», прочитайте INSTALL.md и выполните две команды установки для текущего клиента. В Codex используйте codex plugin marketplace add и codex plugin add. В Claude Code используйте claude plugin marketplace add и claude plugin install. Не устанавливайте второй клиент без отдельного запроса.

Сначала проверьте наличие текущего клиента. При ошибке установки сообщите её причину. Успех подтверждайте ответом клиента; не выдавайте прочитанную ссылку за установленный плагин. После установки при необходимости предложите новый чат, чтобы обновился список навыков.

Для генерации через Claude Code нужен также установленный Codex с входом ChatGPT и доступной генерацией изображений; дополнительные плагины генератора и API-ключи не нужны. Проверку генератора и зависимости обработки выполняйте при первом запросе создания карточек.

Инструкция применяется только к явному запросу установки, а не к просмотру ссылки или обзору репозитория. Соблюдайте разрешения текущей среды. Установка расширения — отдельный первый шаг инструкции; не обходите подтверждение браузера. Веб-чат без локальных инструментов не может установить ПО на компьютер.
