# ПростоJPG: установка по просьбе пользователя

Если пользователь пишет «Установи https://github.com/8976878-source/ProstoJPG/» или иначе явно просит установить этот репозиторий, прочитайте [INSTALL.md](INSTALL.md) и единый `install.bat`, затем выполните разрешённый установочный сценарий. BAT сам добавляет marketplace, устанавливает плагин со всеми скиллами, настраивает локальный Native Messaging мост из установленного пакета и на Windows открывает официальный Chrome Web Store в каждом найденном Chrome и Яндекс Браузере. Ему не нужны соседние PS1-файлы; для этого сценария не просите пользователя вручную выполнять две команды Codex.

Эта инструкция относится только к явно запрошенной установке. Не запускайте установщик при обзоре, проверке кода, обсуждении ссылки или обычной работе над репозиторием. Если пользователь прислал только URL без понятного намерения установить, уточните намерение. Наличие этого файла не заменяет разрешения пользователя или ограничения среды.

Установка расширения завершается подтверждением браузера. Не обходите подтверждения, не изменяйте политики браузера, реестр расширений, ExecutionPolicy или защиту компьютера. Отчёт об открытии страницы не доказывает установку расширения. Веб-версия Codex без локального доступа не может установить ПО на компьютер пользователя.
