# ПростоJPG: установка по просьбе пользователя

Если пользователь явно пишет «Установи https://github.com/8976878-source/ProstoJPG/», прочитайте INSTALL.md и установщик. Для локального Codex на Windows выполните единый install.bat: он добавляет marketplace, устанавливает плагин и открывает магазин расширений в найденных Chrome/Яндекс Браузере. Python, Pillow, Native Messaging и реестр при установке не настраиваются.

Если пользователь просит установить в Claude Code, выполните команды Claude из INSTALL.md. Не считайте BAT установщиком Claude. Для генерации через Claude нужен установленный Codex с входом ChatGPT; дополнительные плагины генератора и API-ключи не нужны.

Инструкция применяется только к явному запросу установки, а не к просмотру ссылки или обзору репозитория. Соблюдайте разрешения текущей среды. Не обходите подтверждение установки расширения в браузере. Открытая страница магазина не доказывает установку. Веб-чат без локальных инструментов не может установить ПО на компьютер.
